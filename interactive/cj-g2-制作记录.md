## 六、本轮踩坑（已修）

1. **★★ 区 C 横幅注释吞掉 `const GAME_CONFIG`**：生成脚本用正则整块替换区 C 时，结尾的 `▲▲▲ */` 被丢弃，导致起始横幅 `/* ▼▼▼ ... ▼▼▼` 一直闭合到区 C 末尾，**整个配置连同 `const GAME_CONFIG = {...}` 被注释掉**，页面报 `GAME_CONFIG is not defined`。定位方法：`grep -n "▼▼▼\|▲▲▲"` 核对横幅是否成对。**教训：区 C/D 横幅的闭合符必须显式写在正则替换文本里。**
2. **ANNOS 未随案例改写**：替换区 B 删掉了 R_B1/R_B2/R_E/C_E 相关元件，但 `ANNOS` 字典仍是 cj-g1 文案，导致布局自检报 `ANNOS 缺: ['wire-rb-a','comp-rb','wire-rb-b']`（exit 1）。**教训：`ANNOS` 必须与区 B 的 id 集合一一对应，删元件必须同步删/改注解。**
3. **I_CQ 框架/表达式空数不一致**：`I_CQ = β·{box}` 只有 1 个虚框却配了 2 个空，导致第 3 关第 2 个表达式子步只渲染 1 个虚框、`no-box` 卡死。修正为 `I_CQ = {box}·{box}`（β 也虚线框化），框架三个选项同步改为 `[2,1,1]` 框。**教训：等号右侧的量一律虚线框化（框架与填空同步），配 `check_boxes.js` 断言框数==空数。**
4. **回归脚本五连问答案表写错（第 4 次迭代才暴露）**：原脚本硬编码 `TQ = [['rbe',…],['rbe',…],['rbe',…],['↑i_b',…],['↑βi_b',…]]` 后统一取 `TQ[k][0]`，导致**第 2、3 问（正确答案 `开路`/`受控源`）一直点 `rbe`**；且方向问选项 DOM 文本是 `↓ib`（下标渲染为 `<span>`，无下划线），`no-opt` 匹配失败后 `break`，五连问未走完 → `drawDone` 永不成立 → 卡死在第 4 关 71 分。修正：**答案运行时从页面 `TQUIZ[d.tquiz.step].ok` 读**，比较前 `norm(s)=s.replace(/[\s_]/g,'')` 归一化。**教训：回归脚本不得硬编码答案表，一律从页面内部状态读；下标类选项的 DOM 文本与配置字符串不同，须归一化后比较。**
5. **误判"下移目标未计分"**：`整理电路 → 71` 看似丢分，实为引擎既定语义（`moveIds` 只计进度不计分；`comp-t` 的分走五连问池）。排查前应先读 `chooseDrawOption` 的 `t-equiv` 分支与 `renderDraw` 的 `per` 计算，勿凭现象改引擎。

## 七、自动化回归要点（`regress_g2.js`）

- headless 无 TTS → `addInitScript` 覆写 `window.speechSynthesis`（`speak(u){ setTimeout(()=>u.onend({}),2) }`）+ `SpeechSynthesisUtterance` 构造器。
- **答案表一律运行时从页面内部状态读**（`TQUIZ[step].ok`、`S.mix[lv].steps[si].opts.findIndex(o=>o.correct)`），不硬编码——硬编码过一次，第 2/3 问全点成第一项，直接卡死关卡。
- **含下标的选项**：DOM `textContent` 是 `↓ib`（下标为 `<span>`，无下划线），须 `s.replace(/[\s_]/g,'')` 归一化后精确比较，不要用「包含匹配」糊过去。
- **`data-blank-level` 是关卡索引**（第3关=2、第5关=4），不是子步号。
- **点虚框 + 点电路元件必须在同一次 `page.evaluate` 内连续完成**：点框触发 `render()` 重建面板，拆成两次 evaluate 会出现空档导致 `selBox` 失效。
- **引擎在 mix 子步完成后用 `addT(..., 1600)` 延迟推进**，脚本每步后须等 >1600ms。
- **框架选项顺序随机**（`shuffle`），按 `S.mix[lv].steps[si].opts.findIndex(o => o.correct)` 取正确项下标再点第 N 个 `.g-opt`。
- **建议写法：完全状态驱动**——每轮读 `S.mix[lv].steps[si]` 的 `type` 与未答空的 `ansIds[0]`，不硬编码子步顺序，比按固定序列点击稳得多。
- **二级菜单须一次 hover 后链式点选**（置零→短路/断路、下移→与XX串/并），重新 hover 会重置回一级菜单。
- `waitForFunction(fn, arg, {timeout})` 第二参是 arg 不是 options。
- 全程约 2 分钟，须 `run_in_background=true` + `TaskOutput` 轮询（前台会超时）。
