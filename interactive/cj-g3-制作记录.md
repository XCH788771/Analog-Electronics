## 一、案例定位

| 项 | 内容 |
| --- | --- |
| 电路 | 双电源（±V_CC）共射放大电路，**发射极分段电阻 + 部分旁路** |
| 器件 | +V_CC 端子、R_C、C_C、R_L、V_o；输入 V_s + R_S、C_B、R_B；NPN 晶体管 T；发射极 **R_e1 + R_e2 串联**接 −V_EE；C_E **只旁路 R_e2** |
| 核心教学点 | **C_E 部分旁路** → R_e1 仍留在交流通路中，故 A_v 分母是 `r_be+(1+β)R_e1`（而非全旁路时的 `r_be`）；R_e2 交流被短路 |
| 题面 | 元件参数用符号给出（不给数值），求静态工作点与动态性能指标 |
| 静态 | V_BQ≈0（R_B 接地、I_BQ 很小）→ V_EQ=−V_BE → I_EQ=(V_EE−V_BE)/(R_e1+R_e2) → I_CQ≈I_EQ → V_CEQ=V_CC+V_EE−I_CQ·R_C−I_EQ·(R_e1+R_e2) |
| 动态 | A_v=−β(R_C∥R_L)/(r_be+(1+β)R_e1)、R_i=R_B∥[r_be+(1+β)R_e1]、R_o≈R_C |
| 系列位置 | 共射系列第 3 个游戏案例（cj-g3），双电源类型内的案例1 |

**与 cj-g1/cj-g2 的差异**：① 双电源（V_CC 与 V_EE 都保留/置零）② 发射极**两段**电阻，只有下段被旁路 ③ 四个接地符号各自独立（无公共地轨）④ R_B 直接接地 → V_BQ≈0 是本电路静态计算的起点。

## 五、本轮踩坑（已修，务必记住）

1. **★★ `y1` 误写成两次**（`<line x1="62" y1="543" x2="118" y1="543">`）→ 属性解析取后者，导致接地横线从 (62,0) 到 (118,543)，报「越过顶部」+9 处「导线交叉」。**接地符号三横线写完必须逐行核对 y1/y2**。
2. **★★ 构建脚本覆盖引擎改动**：先手改 `cj-g3.html` 再跑 `_build_g3.py`，14 处引擎改造全部丢失（页面仍能跑但 `?lvl=4` 钩子报错、菜单文案回退）。**改动一律先进 `_patch_g3.py`**。
3. **★★ 分值未配平**：第 5 关 `Σ子步 = 25` 而 `pts = 24` → 满分通关得 **101 分**。回归脚本断言 `score === 100` 精准暴露。**新增 mix 关后先做配平核算**。
4. **等效态两处残留**：① `fx-vee` 未收起 → −V_EE 接地标记孤零零挂在图下方；② `eq-layer` 的 V_s 接地线漏了 `H 150` 水平段 → V_i 下端子悬空。**showEquiv 改完必须 `?lvl=4&ts=6` 截图目检**。
5. **整理态 R_C 标签粘连**：原放体左侧 (598,337)，与晶体管 E 标注仅隔 27px、与 R_L 标注仅隔 62px → 改放体下方居中 (640,420)。
6. **Q 点标注过密**：V_BE 与 I_EQ 净隙仅 8px → V_BE 整体上移 11px 至 19px（净隙达标）。**fx-layer 不在静态自检范围，必须 Playwright 实测**。
7. **回归脚本三个环境坑**（详见 `regress_g3.js` 头注）：
   - `window.speechSynthesis` 是**只读访问器**，赋值被静默忽略 → TTS stub 无效，`completeLevel` 永不触发（卡在第 2 关）。**正确做法是页面加载后覆写 `speakSeq`**（同步走完 onStart/onEnd 并立即回调 onDone）。
   - 悬停菜单必须**派发 `mouseenter`**：SVG 只在「有 paint 的子元素」上命中测试，透明热区（`fill=none stroke=none`，如 comp-t）中心点命中不到，真实鼠标移入会静默失败。
   - q* 电量标注在 `fx-layer`（`pointer-events:none`）内，真实鼠标点不中 → 用 `dispatchEvent` 冒泡到 `.stage` 委托。
   - 二级菜单要**先 hover 一级项**展开，再点二级项；`waitForFunction` 第 2 参是 arg 不是 options。
