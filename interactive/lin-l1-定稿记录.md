## 计算过程演示（按参数分段：Av / Ri / Ro 三段，面板参数按钮触发）

0. "电压放大倍数的计算。" → 面板第一行出主题名"电压放大倍数 Aᵥ"（y=330）
1. "首先求Vp，因为虚断，同向端电流为0，所以，威p等于威埃。" → Vp 红点闪4 + Ip 红箭头闪3(延时1700) + 面板"Vp=Vi"(延时3200)

3. "因为虚断，反向端电流为0。" → In 蓝箭头闪3
4. "这时，R1与R2相当于串联。" → R₁/R₂ 变紫闪3保持紫（res-purple）
5. "I1与I2相等。" → I₁/I₂ 箭头闪3 + 面板"I1=I2"(延时900)
6. "用电位差可表示出R1和R2的端电压，进一步表示出I1和I2。" → R₁接地+R₁上节点(387,580)+输出节点(760,400) 变绿闪3保持绿
7. "经数学变换可得到，电压放大倍数Av，等于1加R1分之R2。" → 面板"Av=Vo/Vi=1+R2/R1"

面板步骤 5 行：主题名 / Vₚ=Vᵢ / Vₙ=Vᵢ / I₁=I₂ / Aᵥ=Vₒ/Vᵢ=1+R₂/R₁（46px，tspan.sub 下标，首行 y=330 步进 105）；面板标题"计算过程"字号 46（与步骤同大；**面板不触发演示**，触发统一走参数分段按钮），无提示小字；全页英文/数字 Times New Roman（内嵌子集），中文黑体 SimHei。

## 关键技术点（改动时勿破坏）

- speakSeq 分句 + seqId 令牌（移开/关闭作废未播句）；无 TTS 按字数 200ms/字推进
- **calcSpeaking 互斥规则（2026-09-26 新增）**：计算演示语音播放期间（calcSpeaking=true），悬停其它元件只显示文字注解、不播语音、不触发 onStart 演示、mouseleave 不 stopSpeak——保证 7 句推导声画完整不被打断；演示结束两标志复位
- 演示图层全部 pointer-events="none"；+/- 热区不触发运放本体
- resetCalc 覆盖：calcIds 全部隐藏 + 清 res-purple/green-flash + 清步骤
- 闪烁节奏：3次（重点4次）× 0.22s
- 语音音译：V=威/微 N=恩 P=批 i=埃；语音稿不用"相"字（同向/反向）、不出现符号
