## 三、绘图规范

- 元件/导线一律包 `<g class="interactive" data-id="..." data-name="...">`，内部图形加 `class="hot"`，文字加 `class="hot-label"`（悬停自动金黄高亮）。
- 线宽 3.5；标注字号 37（元件名）、小字 20-23；"+"黄色、"−"浅蓝、其余白色。
- **每个元件和每条导线都是独立交互单元**，无遗漏（自查清单第 1 条）。
- **屏幕标注只保留元件符号**（Vᵢ/R₃/A/Vₒ…），不显示元件编号（如 V1）、不显示公式小注（如 R₃=R₁∥R₂）——避免杂乱压线。
- 输入端 +/− 从运放本体独立出来，各带 `r=26` 隐形热区（`fill="transparent" pointer-events="all"`）。
- **矩形元件（电阻框等 fill="none"）必须内部可命中**：SVG 默认 `visiblePainted` 只认边框，框中间是悬停/点击死区。模板 CSS 已内置兜底规则 `.interactive rect[fill="none"] { pointer-events: all; }`（2026-09-28 lin-g1 踩坑后回灌模板 + lin-l1/lin-t4/lin-g1 四个文件），新页面复制模板自动继承，勿删。
- 演示用图层（箭头、圆点、节点圈）必须加 `pointer-events="none"`，不拦截悬停。
- 节点圆点装饰 `r=7` 白色；演示态绿色节点 `r=11` 盖在上面。
- **★ 下标必须用 `baseline-shift: -20%`，禁止 `baseline-shift: sub` 关键字**（2026-10-01 踩坑）：Chrome 对 SVG tspan 的 `sub` 关键字位移量随字号增大异常放大——60% 时正常，88%/100% 时下标直接被甩到"下一行"错位。统一写法：`tspan.sub { font-size: 100%; baseline-shift: -20%; }`（模板与全部已建页面已回灌，勿改回 sub）。**字号保持 100%（等大）**：用户反馈 75% 已看不清（下标多为小写字母，x-height 天然矮 + Times 细衬线），只允许调位移、别调小字号；svg-layout-check.py 的 SUB_SCALE=1.0 与之同步。
- **★ 标签避让（2026-10-01 定，数值基准 = lin-g1 实测）**：元件标签墨迹（含 100% 下标下沉 20%）与元件图形**净间隙 14~21px**——横向电阻标签基线 y = 电阻上沿 − 22（≈14px）；端子/侧向标签 ≈ 20px。**大于 30px 即「过空」**（lin-g4 教训：标签悬空显得散，用户点名批评），小于 8px 会压元件（lin-t4/lin-g1 R₃R₄R₅、lin-g3 R₁ 曾压上沿，已修）。**导线不得从「标签与元件之间」的空档穿过**：该空档属于标签，走线绕行（上方绕行留 ≥15px 净空）或改标签位置；绕行形成的 T 形接点补 r=7 白色节点圆点（lin-g4 Vₒ₁ 引出线即为范例）。
- **★ 元件布局均匀（2026-10-01 定）**：元件最近邻净间隙 ≥ 20px、同类元件间距差异 ≤ 1.5 倍——不许一半拥挤一半空洞；**元件两端导线长度尽量接近（比值 ≤ 1.5:1）**，避免一端贴死、一端拖长。违例由自检工具第 ⑦/⑧ 项自动报出。

## 四、语音与文案约定（TTS 踩坑总结，必须遵守）

1. **电压用 V 不用 u**：Vᵢ 输入、Vₒ 输出、V₊=V₋ 虚短（教材惯例，全站长期）。
2. **屏显与语音两套文字**："同相/反相"屏显用"相"，语音稿写"同**向**/反**向**"（纠正 TTS 发音）。
3. **TTS 不读符号**，语音稿全用中文/音译：
   - 音译表：V=威/微，N=恩，P=批，i=埃 → 如"Vn等于Vp等于Vi"写作"威恩等于威批等于微埃"
   - 公式念中文："Av=1+R2/R1" → "电压放大倍数Av，等于1加R1分之R2"
   - 元件名用中文词："Vi"会读成"微埃"，信号源称"输入信号源"
4. **分句播放**（speakSeq）：演示动画写在对应句子的 `onStart` 里，与语音开口精确同步。
5. **语音互斥（calcSpeaking，框架已内置）**：计算推导语音播放期间，悬停其它元件只显示文字注解、不播语音，鼠标移开也不打断演示声画——保证多句推导完整播完。
6. 语音稿语气口语化，一句一个动作。

### ★ 布局设计对齐范式（2026-10-01 lin-g4 第 5 轮定，先算后画，禁止挤牙膏式微调）

横向重排不要一轮挪 10~20（960 宽的图上视觉不可见），一次到位用**约束方程**解坐标：

1. **节点居中范式**：某段导线两端的元件定下后，分支节点取两端 x 的平均值；
2. **电阻居中范式**：「电阻在 A 与 B 之间居中」→ 电阻中心 = (A_x + B_x)/2；
3. **对齐范式**：上下两条水平支路（如 R₁ 分压、R₃ 接地）左端对齐 + 运放两输入端同 x ⇒ 两条支路的节点自动同轴，一处居中处处居中；
4. **减半范式**：用户说"导线长度减半/移到一半"= 新长度 = 旧长度/2，据此反推运放新位置（尖端 = 远端 − 旧长/2）；
5. 改动量按"一眼可见"标准：横向 ≤40 的挪动在整图上几乎不可辨，重排至少 80+；
6. 每轮改完必跑自检脚本 + 截整图，与用户描述逐条对照断言（可用临时 python 断言脚本核验"节点=中点""两电阻同 x"等约束）。
