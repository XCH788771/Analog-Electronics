## 四、电路绘制规约

### 4.1 元件尺寸与样式（固定，不得改）

| 元件 | 几何 | 关键样式 |
|---|---|---|
| 电阻（竖放） | `rect 27×53` | `stroke-width 3.5`，无填充 |
| 电阻（横放） | `rect 53×27`，如 R_L | 同上；文字水平正向、居中于上方 |
| 晶体管 | 基极条 `line stroke-width 10`（长 72）+ 两条斜线 `7` + 发射极箭头 polygon | NPN 箭头朝外 |
| 恒流源 | `circle r26` + 内部水平线 | 填充 `rgba(255,255,255,0.10)` |
| 端子圆 | `circle r8`，填充 `#0a3d20` | 电源/输入端口 |
| 节点圆 | `circle r7`，**`pointer-events="none"`** | 集电极白、基极/发射极紫 `#a78bfa` |
| 输出端点 | `circle r8` 填充 `#34d399` | 文字同色、位于点正上方 10px |
| 导线 | `path stroke-width 3.5` | 全部水平/垂直，**不得斜接**（斜线仅晶体管内部） |

### 4.2 交互分组与命名

每个元件/导线/端子独立成组：`<g class="interactive" data-id="...">`，可见形状加 `.hot`（部分加 `.hot-label`）。

| 前缀 | 含义 | 例 |
|---|---|---|
| `comp-*` | 元件（电阻、晶体管、恒流源、端口、输出端点、节点标注占位） | `comp-rc1`、`comp-t1`、`comp-io`、`comp-rl`、`comp-vo1` |
| `wire-*` | 导线 | `wire-vcc-rail`、`wire-e1`、`wire-io-a` |
| `node-*` | 不可交互节点圆（`data-id` 仅供 ANNOS 说明） | `node-col1`、`node-base1`、`node-emitter` |
| `q-*` | Q 点电量标注（fx 层，可点击作答） | `q-ieq1`、`q-veq`、`q-vbe1`、`q-beta` |

**所有 `data-id` 必须在 `frag_ANNOS.js` 中有对应条目**（`svg-layout-check.py` 会校验，缺一即 exit 1）。

### 4.3 必须遵守的三条硬规则

1. **`data-name` 不得写答案**：`data-name` 会进语音朗读，只描述「是什么」，不得出现 `V_BQ=0`、`I_EQ1=I_EQ2` 这类等式或结论（r134 口径）。
2. **热区不得越界**：透明热区 `rect.hot` 覆盖本元件本体；标注热区不得覆盖晶体管、电阻等元件热区（df-b1 的 `q-vbe1` 拆成三枚独立热区即为此）。
3. **元件位移后必须真实鼠标验证命中**：热区坐标与可视形状同步改；隐藏层 `opacity=0` 仍参与命中，关态须加 `hit-off`。

### 5.2 间距口径（用户已裁决，勿再改）

- 「距端子圆圈 15px」按**字形盒**口径（37px 标签盒底 = baseline + 8）；按墨迹口径会触发检查器③「标签压元件」。
- 「距直角 / 箭头 10px」按**墨迹**口径。
- **37px 斜体带下标**（如 `I_O`）墨迹右溢约 3.4px：`text-anchor=end` 时要把 x 再左移 3.4px 才能得到视觉 10px。
- 旋转判据一律用 `getCTM()` 四角换算，**不得用 `getBBox()` 宽高比**（r133 假失败教训）。
- **正方向 = 不写 `rotate`**（r135 用户裁决）：`transform` 为空、CTM 单位阵即为横排正方向。

### 5.3 连等量同组（r131 定稿）

两个恒等量（如 `I_EQ1`/`I_EQ2`）必须包进同一父 `<g>`（df-b1 为 `#ieq-blink-pair`），由**父容器单一** `calc-blink` 驱动；子标注不得各自挂动画类，且 `blinkGroup` 调用处须有「自身或 `.closest('.calc-blink')` 已在闪则跳过」护栏（`fw-blink-guard` 补丁）。否则一次性红闪会打断连续动画、令两管错相约 0.24s。

## 六、计算关卡设计

### 6.1 两关骨架（df-b1 基准，合计 100）

| 关 | 名称 | 分 | 子步结构 |
|---|---|---|---|
| 1 | Q 点计算 | 48 | `fw` I_EQ1（8）→ `fill` I_EQ1 表达式（I_O 4 + 常数 2 4）→ `fw` V_EQ（8）→ `fill` 代入符号（V_BQ 4 + V_BE 4）→ `fill` 代入数值（4 空 ×4） |
| 2 | 动态指标 | 52 | `fw` r_be（4）→ `fill` r_be（β 4 + I_EQ 4）→ `fw` A_vd（4）→ `fill` A_vd（12）→ `fw` R_id（4）→ `fill` R_id（4）→ `fw` R_o（4）→ `fill` R_o（4）→ `fw` A_vc（4）→ `fill` K_CMR（4） |

**配平恒等式（硬性）**：`Σ(所有子步 qpts + 所有 blanks pts) == 该关 pts`，且 `Σ 各关 pts == 100`。探针必须断言，改任何一处填空都要重算。

### 6.2 框架（`type:'fw'`）三选项规则

1. 三项**结构互异**（分式 / 乘式 / 单框 / 具体数值，任选不同组合），不能三项都是方框；
2. 正确项只标 `correct:true`，其余不得含正确项的特征符号（如 `∥`、`/`）；
3. 题干 `fwQ` 单行 26px、≤520px，统一格式「〈量名〉的框架：」，**括号补充说明一律删除**（r130）；
4. 干扰项可用方框，也可用**具体数值**（100 以内、非 0 非 ∞，编译期定值不运行时随机）——是否替换由用户裁决（r138：A_vc 的 `−□/□` → `−62`）；
5. 必须给 `qid`（闪烁定位用，指向等号左边的待求量标注）。

### 6.3 填空（`type:'fill'`）规则

1. `fullExpr` 的虚线框总数 **必须等于** `blanks.length`；
2. 常数一律方框化：`{num:'<值>', pts:0}`，走数字键盘、答对不报分（r130/r132 定稿：`r_be` 的 200/1/26 全方框）；
3. 参数空用 `ansIds` 指向电路中可点的 `data-id`；同一量有两个位置时给双 id + `labels` 映射（如 `comp-rc1`/`comp-rc2`）；
4. 需要「点按钮 + 点电路」双路径时加 `pickBtn:true`；**是否保留按钮由用户裁决**（r137：R_o 的 R_C 空去按钮，只点电路）；
5. 多解空用 `alts`（点标注 **或** 输数值均正确），回填 `pickedLabel`；
6. 需要「按钮即答案」时用 `{btn:[tk('A','vd')], pts:n}`（无 `ansIds`，点 `.sym-key` 直接计分）；
7. `padHint` ≤520px、只写操作步骤，不得出现公式/常数/结论；同一步内多空作答路径不同时，措辞要覆盖差异（如「其余量点电路标注」）。

### 6.4 键盘三种形态（引擎已就绪，配置选型即可）

| 形态 | 触发条件 | 布局 |
|---|---|---|
| 数字键盘 | 子步 `numPad:true` 且含 `num` 空 | 10 数字键 + 第 6 列「确认」两行 |
| 数字 + 参数按钮 | 同上且有 `pickBtn` 空 | 数字键 + 确认 + 右侧参数按钮 |
| 符号键盘 | 子步含 `btn` 空 | 紧凑 7 列×2 行 14 键：0-9 + 各符号键 + 确认；**符号键顺序随机**（进步时洗牌一次存 `st.btnOrder`，步骤内不重排） |

补充：常数输入后点键盘/虚线框**以外**任意位置＝自动确认；切换虚线框时若有未提交数字先自动提交。

### 6.5 闪烁（`calc-blink`）

- 只闪**等号左边的待求量**（由 `subs[].qid` 定位）；参与代入的已知量（V_BQ、V_BE）不闪（r129 定稿）。
- 连等式（`I_EQ1=I_EQ2=…`）两个待求量可同闪，必须走第 5.3 节的同组单一动画。
- 动态关（`updateQlabels`）无 `qid` 时不闪；只藏 V_EQ，其余标注常显。

## 七、语音与提示口径（r134 定稿，全站强制）

`announce` / `extra` / `doneSay` / `subLine` / `padHint` / `ANNOS.text` / `parts` / `data-name` 一律**只说「做什么、先做什么再做什么」**。禁止出现：待求量公式或等式（`V_EQ=V_BQ−V_BE`、`两管电流各占一半`）、答案常数（200、26、0.7）、直指答案的操作口令（「分子点恒流源」）、结论性判断（虚地、共模抵消、共模抑制最强）。

不受限：题设条件、`fwQ` 题干、已知行、报分串、推导讲解类语音。TTS 注音：R=阿尔、I=艾、B=碧、Q=口、V=威、N=恩、P=批、i=埃；「同相/反相」读「同向/反向」。

## 十一、已知坑（差分放大系列专属）

1. **嵌套分式会溢出括号**：引擎不支持 `fr` 套 `fr`，`R_L/2` 用横式 `□/□`（r135）。
2. **新增填空不能直接 +4 分**：须按单元等比重配（3 空×4 → 4 空×3 → 5 空 3/3/3/0/3），否则满分变 101。
3. **`fx-layer` 新增组必须写 `opacity="0"`**：初始加载不走 `resetCircuit`，漏写会常显。
4. **`resetCircuit` 的通用 `g` 循环不覆盖 `circle`**：节点圆显隐须单独 id + 显式恢复。
5. **检查器 ⑦ 只比不同 `data-id` 元件组**：同组装饰子形状（恒流源圆 + 自身箭头）8~10px 贴身不算拥挤（r132 放宽）。
6. **隐藏层仍可点击**：关态加 `hit-off`；叠在可点 rect 上的回显文字必须 `pointer-events:none`。
7. **同组连等量闪烁必须同步**：见第 5.3 节，自检须读父容器或合成 opacity（只读子元素会假性通过）。
8. **`data-name` / 语音漏题**：新增标注时逐一核对第 7 节禁用词，别漏 `data.js` 案例卡 `desc`。
9. **菜单 label 不可含 HTML**：`showMenu()` 用 `d.textContent = it.label`，写 `r<tspan class="sub">O</tspan>` 会在菜单里显示字面标签；统一写纯文本 `rO`（SVG 标注本身仍用 `<tspan>`）。
10. **互斥状态层必须放进 `#fx-layer`**：检查器只豁免 fx-layer 内的隐藏层；把等效态层放在 `circuit-wrap` 末尾会与主电路静态一起被扫，误报压元件/拥挤（r146 实际踩坑）。
11. **`opacity=0` 不等于不参与命中**：隐藏层里 `g.interactive[pointer-events=all]` 与 `rect.hot`（CSS `pointer-events:all`）仍会拦截下层元件的 hover/点击（r147 根因）。隔离时须对**子组及其全部后代**写 inline `none`（父组设置会被子元素自身 CSS 覆盖），且**不要改父层 style**，否则抹掉 `showCmTail` 写入的 `all`；用 `MutationObserver` 监听 `#fx-layer` 的 style 变化即时同步，不能只靠 `mousemove`。
12. **悬停热区跨多个子元素时用几何判定**：`getBBox()` + `getScreenCTM().inverse()` 判定局部坐标，比依赖 `mouseenter`/`elementFromPoint` 更稳，能在文字与箭头之间的空隙保持连续触发，也不受上层透明层影响（r147 的 `comp-io` 恒流源圆 + I_O 文字 + 箭头统一热区）。
