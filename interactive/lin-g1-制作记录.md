## 通用引擎说明（换案例怎么做）

- 引擎代码在 lin-g1.html `<script>` 内"游戏闯关引擎"段，与电路解耦；
- **换新案例只改两处**：① 电路 SVG（复制对应电路页的图形段）；② `GAME_CONFIG`（每级的 typeOptions/typeAnswer/typeWhy、frameworks tokens、顶层 av（options/answer/why/say）（`tk(主,下标)` 文本片段 + `{box:1}` 虚线框）、blanks 的 `ansIds`（填空答案＝电路 SVG 交互单元的 data-id））；
- **typeAnswer 与 av.answer 写原配置顺序下的正确项下标即可**——引擎在 initState() 自动对 typeOptions/frameworks/av.options 做 Fisher-Yates 洗牌（每次挑战、每次重新挑战都重新洗），并重映射正确索引，换案例无需关心显示顺序；
- **计分微调只改 `pts: { type, fw, fill, avFw, avFill }`**（fill 为第2关每级分值；avFw/avFill 为第3关框架/填空分值，第3关框架配置在 `av.frameworks + av.blanks`，作答复用 renderL3('av')，data-blank-stage='av' 需绕过 parseInt），扣分比例自动按 1/n 与空数均分推导；总分 = (type+fw+fill)×2 + avFw + avFill；
- 电路级分组在 `STAGE_UNITS`（两级交互单元 data-id 列表），换电路后同步更新；
- 语音/屏显约定沿用全站规范（同相/反向分离、speechify 自动替换）；av.why 屏显（tspan 下标）与 av.say 语音（纯中文数字）分离；TTS 反馈语随作答实时播报。
- 调试快捷方式：URL 加 `?lvl=2（第2关框架态）/ ?lvl=3（第2关填空态预览）/ ?lvl=4（第3关框架态，加 &ph=fill 预览填空态）/ ?lvl=done`，可加 `&st=0/1`（截图/自查用）；`getState()` 为只读测试钩子。
